# Vocaret companion promo

Editable HyperFrames source for the current **36-second, silent, 1920×1080** companion film. See [BRIEF.md](BRIEF.md), [STORYBOARD.md](STORYBOARD.md), and [VERIFICATION.md](VERIFICATION.md).

```sh
npm run check
npm run render -- --quality high --fps 30 --workers 2 --output ../docs/assets/vocaret-companion-promo.mp4
```

If your default npm cache has permission errors, set `npm_config_cache` to a writable temporary directory. The project retains its tested HyperFrames pin.

The orbital sphere is original deterministic CSS 3D geometry animated by GSAP. The glass UI scenes are illustrative layouts with synthetic text, not recorded product interactions. Remember creates a local draft and requires Save; Codex/Claude are optional, explicit requests using a signed-in CLI account.

Assets: original Vocaret icon; Barlow Condensed font with bundled OFL; existing vendored GSAP. No stock media, private recordings, voiceover or music. Final web files live in `docs/assets/vocaret-companion-promo.mp4` and `docs/assets/vocaret-companion-poster.jpg`.
