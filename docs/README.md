# Design notes

These are the original planning documents, written before and during the initial
implementation (when the project was called "JustSayIt"). They are kept for
context on *why* the architecture looks the way it does.

**They are historical.** Where they disagree with the code or the top-level
README, the code and README are authoritative — hotkeys, defaults and several
components changed after these were written.
