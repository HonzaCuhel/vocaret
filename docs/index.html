03 / Memory, on your terms

Say it.
Choose to
remember it.

A thought doesn’t need to become a request to an AI agent.

  1. 01

    Finish dictating

    Your words go where you’re working.

  2. 02

    Click Remember

    Open the last dictation in an editable local memory draft. No agent call.

  3. 03

    Review, then save

    Only save what you want to keep. Closing the draft leaves saved memory unchanged.

Bring in an assistant when you choose.

Choose Ask assistant to open an editable draft from your last dictation. Send explicitly through your signed-in Codex or Claude CLI; this shares chat and Vocaret memory with the agent. Review memory proposals before saving.

Before you install

This build is ad-hoc signed and not notarized by Apple. macOS may block opening it; review the release instructions before installing. Microphone access is required for dictation, Accessibility for inserting text, and Screen & System Audio Recording for meetings. Local speech models download separately.
